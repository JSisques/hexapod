# Architecture Decision Records

Significant decisions are recorded here as ADRs in the Nygard format, extended with an "Alternatives considered" section.

## Naming

`NNNN-kebab-title.md`, where `NNNN` is a zero-padded sequence number (for example `0001-repository-layout-and-licensing.md`).

## Status values

- Proposed
- Accepted
- Deprecated
- Superseded (link to the superseding ADR)
